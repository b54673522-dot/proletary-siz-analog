# Пролетарий: подбор аналогов СИЗ

Простая первая версия веб-приложения для компании "Пролетарий".

Задача приложения:

1. Добавить сайты или каталоги производителей СИЗ.
2. Собрать товары производителей в единую внутреннюю базу.
3. Вставить описание товара конкурента.
4. Получить 3-5 подходящих аналогов из ассортимента производителей.
5. Сохранить выбранную связку "товар конкурента -> наш аналог".

## Как запустить приложение

1. Установите Python 3.10 или новее.
2. Откройте папку проекта.
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите приложение:

```bash
streamlit run app.py
```

5. В браузере откроется страница приложения.

## Куда вставлять сайт производителя

На странице есть блок "База производителей".

Заполните:

- "Производитель" - название производителя;
- "Ссылка на каталог производителя" - ссылка на страницу каталога или раздел с товарами.

После этого нажмите "Добавить сайт".

## Как обновлять базу товаров

После добавления сайтов нажмите кнопку "Обновить товары".

Приложение попробует открыть страницы производителей, найти карточки товаров и сохранить их в файл:

```text
data/products_cache.json
```

На странице будет показано:

- сколько производителей подключено;
- сколько товаров собрано;
- дата последнего обновления.

## Как вставлять позицию конкурента

В блоке "Позиция конкурента" вставьте описание товара конкурента в большое поле.

Например:

```text
Костюм летний для защиты от общих производственных загрязнений, ткань смесовая 210 г/м2, куртка и брюки, цвет синий, СОП.
```

Поле "Ссылка на товар конкурента" можно оставить пустым.

Затем нажмите "Подобрать аналог".

## Как проверять результат

После подбора приложение покажет:

- что система определила в описании конкурента;
- таблицу подходящих СИЗ из базы производителей;
- процент совпадения;
- что совпало;
- что отличается;
- что нужно уточнить.

Статусы:

- 85% и выше - "Сильный аналог";
- 65-84% - "Близкий аналог";
- 45-64% - "Требует уточнения";
- ниже 45% - "Не предлагать".

Если защитные свойства не совпадают, товар не будет считаться сильным аналогом.
Если данных мало, статус будет "Требует уточнения".

## Как сохранить выбранный аналог

В блоке "Подходящие СИЗ из ассортимента производителей" нажмите кнопку "Выбрать" рядом с нужным товаром.

Связка сохранится в файл:

```text
data/confirmed_analogs.json
```

## Что делать, если сайт производителя не распарсился

Первая версия использует простой универсальный сборщик сайтов. Некоторые сайты могут не отдать товары из-за сложной верстки, защиты или загрузки каталога через JavaScript.

Что можно сделать:

1. Попробовать вставить ссылку не на главную страницу, а прямо на раздел каталога.
2. Попробовать ссылку на страницу категории, где уже видны карточки товаров.
3. Проверить, открывается ли ссылка без входа на сайт.
4. Если товары не собрались, для этого производителя нужно будет добавить отдельный парсер под структуру его сайта.

## Файлы данных

Внутренняя база товаров:

```text
data/products_cache.json
```

Подтвержденные менеджером аналоги:

```text
data/confirmed_analogs.json
```

Список добавленных производителей создается автоматически:

```text
data/manufacturers.json
```
